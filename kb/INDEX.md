## Libraries

- [3d-tiles-renderer](libraries/3d-tiles-renderer.md): OGC 3D Tiles for three.js, Babylon.js and R3F, with plugins for Google Photorealistic Tiles and Cesium ion; the base of most three.js geospatial work. (>=r167, webgl, 3d-tiles-renderer 0.5.3)
- [camera-controls](libraries/camera-controls.md): Renderer-agnostic orbit and dolly controls with fitToBox and scripted transitions; a drei dependency and a common OrbitControls upgrade for product viewers. (>=r159, camera-controls 3.1.2)
- [deck.gl](libraries/deck-gl.md): GPU-accelerated map and data layers for millions of points, built on luma.gl rather than three.js; mixing it with a three.js scene needs custom layers or a shared context. (@deck.gl/core 9.4.0)
- [drei](libraries/drei.md): Helper library for React Three Fiber; controls, loaders, Environment, Text, ScrollControls; v10 is stable on WebGL, v11 alpha is the WebGPU line. (>=r159, @react-three/drei 10.7.9)
- [globe.gl](libraries/globe-gl.md): One-call data globes (arcs, points, hexbins) built on three-globe; the fastest path to a globe visualization without owning the scene graph. (>=r179, webgl, globe.gl 2.46.2)
- [glTF Transform](libraries/gltf-transform.md): Scripted and CLI glTF optimization (Meshopt, Draco, KTX2, simplification, joining); the default asset pipeline for every scenario that ships a GLB. (@gltf-transform/cli 4.5.0)
- [gltfpack](libraries/gltfpack.md): One-shot CLI GLB compressor built on meshoptimizer; writes Meshopt-compressed glTF that three r186's loader reads natively. (gltfpack 1.3.0)
- [GSAP](libraries/gsap.md): Timeline and ScrollTrigger animation library, free for all commercial use since 2025; the default engine for scroll storytelling and scripted camera moves. (gsap 3.15.0)
- [Immersive Web SDK (IWSDK)](libraries/iwsdk.md): Meta's three.js-plus-ECS framework for Quest-first WebXR, with the most complete agent tooling (an MCP runtime) of any three.js-based stack; still pins an old three fork. (>=r159, webgl, @iwsdk/core 1.0.0-rc.2)
- [Jolt Physics](libraries/jolt-physics.md): WASM rigid-body engine for large scenes, vehicles and character virtual controllers; three ships a JoltPhysics addon that loads it from a CDN. (>=r159, jolt-physics 1.1.0)
- [Lenis](libraries/lenis.md): Smooth-scroll library that honors prefers-reduced-motion by default; pairs with GSAP's ticker for one shared rAF loop in scroll storytelling. (lenis 1.3.26)
- [lil-gui](libraries/lil-gui.md): Small dependency-free debug panel for vanilla three.js; the current answer to dat.gui, which three itself still bundles an older copy of. (lil-gui 0.21.0)
- [model-viewer](libraries/model-viewer.md): Google's <model-viewer> web component, built on three.js, for showing a GLB with AR (Scene Viewer on Android, Quick Look on iOS) in one tag. (webgl, @google/model-viewer 4.3.1)
- [Needle Engine](libraries/needle-engine.md): Unity- and Blender-to-web runtime built on a three.js fork, with built-in physics, networking and XR; install the stable dist-tag, not latest. (>=r159, @needle-tools/engine 5.1.13)
- [Plotly.js](libraries/plotly.md): Stock 3D chart types (scatter3d, surface, mesh3d, isosurface, volume, cone) with hover and export; not three.js, but the first choice before hand-rolling a 3D chart. (plotly.js 4.1.1)
- [postprocessing (pmndrs)](libraries/postprocessing.md): Merged effect passes for WebGLRenderer (bloom, AO, DoF, and more); the WebGL-only alternative to three's own EffectComposer, with no WebGPU plan. (>=r168, webgl, postprocessing 6.39.5)
- [Rapier](libraries/rapier.md): WASM physics engine for three.js games; the 0.21.0 line adds soft bodies and changed several method signatures from 0.19 and 0.20. (>=r159, @dimforge/rapier3d-compat 0.21.0)
- [React Three Fiber (R3F)](libraries/react-three-fiber.md): React renderer for three.js; v9.8 is the stable line for React 19.3, v10 is an alpha with WebGPU-first hooks; when to use it, how to set it up, and what trips agents. (>=r156, @react-three/fiber 9.8.1)
- [React Three Rapier](libraries/react-three-rapier.md): Rapier physics for React Three Fiber through <Physics> and <RigidBody>; pinned to Rapier 0.19.2 while Rapier itself is at 0.21.0, so new Rapier features need the raw package. (>=r159, @react-three/rapier 2.2.0)
- [Spark](libraries/spark.md): The most capable three.js Gaussian-splat engine, with streaming LoD and a GPU virtual memory pool; WebGL2 only in official releases, versus r186's native WebGPU splat renderer. (>=r180, webgl, @sparkjsdev/spark 2.2.0)
- [stats-gl](libraries/stats-gl.md): FPS, CPU and GPU timing overlay for WebGL and WebGPU; the current replacement for stats.js and r3f-perf. (>=r159, stats-gl 4.2.3)
- [three-mesh-bvh](libraries/three-mesh-bvh.md): Fast raycasts, shapecasts and BVH-based capsule collision against level meshes; 0.9.15 adds a WebGPU TSL/WGSL compute path alongside the pure-JS one. (>=r159, three-mesh-bvh 0.9.15)
- [three-vrm](libraries/three-vrm.md): The durable open avatar path for three.js after Ready Player Me's shutdown; VRM 0.x and 1.0 support, MToon material, and a WebGPU node-material path. (>=r167, @pixiv/three-vrm 3.5.5)
- [Threlte](libraries/threlte.md): Svelte 5 renderer for three.js; v8 supports WebGPU through a createRenderer prop, ahead of the equivalent React and Vue integrations. (>=r172, @threlte/core 8.6.1)
- [TresJS](libraries/tresjs.md): Vue 3 renderer for three.js, the Vue equivalent of React Three Fiber; v5 is stable on WebGL, with experimental WebGPU through a renderer factory. (>=r159, @tresjs/core 5.9.0)
- [troika-three-text](libraries/troika-three-text.md): Worker-generated SDF text for three.js, mature on WebGLRenderer; no WebGPU support yet, so drei's Text component inherits the same limit. (>=r159, webgl, troika-three-text 0.52.5)
